Linguagem de programação é um conjunto de símbolos, palavras-chave e regras que permitem a comunicação entre seres humanos e computadores.

algumas linguagens são voltadas ao desenvolvimento de sistemas e aplicações corporativas (como Java e C#), outras se destacam em ciência de dados e inteligência artificial (como Python e R), enquanto algumas foram projetadas especialmente para aplicações web (como JavaScript e PHP). Existem também linguagens utilizadas em sistemas embarcados e de baixo nível, como C e Assembly

O desempenho esperado é outro ponto: projetos que exigem alta performance e controle sobre o hardware normalmente utilizam linguagens de baixo nível; já aplicações que priorizam rapidez e produtividade favorecem linguagens de alto nível.

### Python

* Curva de aprendizado suave
* Aplicabilidade prática: é utilizado em áreas modernas e de grande demanda, como ciência de dados, inteligência artificial, automação, desenvolvimento web e análise de dados
* Amplo suporte
* Multiplataforma
* Bibliotecas poderosas: existem módulos prontos para praticamente qualquer aplicação, como NumPy (cálculos numéricos), Pandas (análise de dados), TensorFlow (inteligência artificial) e Flask/Django (desenvolvimento web).
