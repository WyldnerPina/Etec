## Prólogo

O app não “adivinha” o que você quer; ele precisa que cada ação venha na sequência correta.
A lógica de programação nada mais é do que organizar o pensamento para transformar intenções em instruções claras que uma máquina consiga seguir.
se as instruções não estiverem claras e na ordem certa, nada acontece como esperado.

para realizar qualquer tarefa, desempenhamos ações organizadas em uma sequência lógica.
saber cada etapa do problema, para que possamos fornecer ao computador uma sequência lógica de passos que a máquina deverá executar para que resolva o nosso problema
Esta sequência lógica é representada pelo algoritmo.

### Raciocínio Lógico
computador só entende instruções claras
**lógica de programação** é a forma como usamos esse raciocínio para ensinar o computador a resolver problemas
organizar instruções em uma sequência clara, que a máquina consegue entender e executar

Definir entradas (o que o usuário informa)
Pensar em processamentos (o que precisa ser feito com esses dados)
E prever as saídas (o resultado que será mostrado)

Todo algoritmo tem por padrão que apresentar algumas características básicas: ponto inicial e ponto final.
Um algoritmo também precisa:
Não ser ambíguo:
Tratar dados externos: poder de receber dados externos e ser capaz de retornar resultados aos mesmos.
Possuir etapas alcançáveis:

entrada → processamento → saída
