# Estrutura de Decisão

Programar é traduzir condições e decisões para uma linguagem que o computador entende

Estrutura condicional → Cada estrutura condicional abre caminhos para automatizar processos, tornar o sistema mais inteligente e prevenir erros que poderiam comprometer a operação ou a segurança dos dados.

## op relacionais
Os operadores relacionais são símbolos usados para comparar valores dentro de uma expressão lógica, sempre será verdadeiro (True) ou falso (False

Eles são usados para:
• Controlar fluxos de decisão (if, elif, else);
• Validar regras (como limites, permissões, faixas etárias, notas mínimas etc.);
• Comparar resultados de cálculos, sensores ou variáveis;
• Filtrar e classificar dados em programas mais complexos

---

```python
idade = int(input("Digite sua idade: "))
if idade >= 18:
	print("Você é maior de idade.")
else:
	print("Você ainda é menor de idade.")
```
